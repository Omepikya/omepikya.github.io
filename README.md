# Omepikya Expense Web

Official public-facing website for **Omepikya Expense**.

**Live site:** https://omepikya.in/

## Current scope

- Responsive landing page
- Product positioning and hero section
- Feature overview based on the Android app
- Security and privacy sections
- App gallery
- Primary Android download CTA
- Dark-mode support
- Mobile navigation
- Lightweight client-side interactions
- SEO metadata, sitemap and robots configuration
- PWA foundation

## Local development

No framework or build step is required. Open `index.html` in a browser or serve the repository with any static HTTP server.
