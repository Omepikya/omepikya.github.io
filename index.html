Privacy

Your financial information deserves respect.

Omepikya Expense is designed around the idea that personal financial information should be handled carefully, transparently, and with user control in mind.

01

Financial information

The app can contain information such as expenses, income, categories, dates, amounts, notes, and other information you choose to enter.

02

Account information

Cloud-enabled features use an authenticated account so that supported financial data can be associated with the appropriate user.

03

Local device data

Some application information may be stored on your device to support the app experience and its financial features.

04

Cloud synchronization

Where cloud features are used, relevant application data can be synchronized through Omepikya's supported cloud infrastructure.

05

Your control

You decide what financial information you enter into the application. Avoid entering information that is not needed for the feature you are using.

06

No unnecessary promises

Omepikya does not use vague privacy claims to hide how the application works. Our goal is to keep the experience understandable as the platform evolves.

Security

Security is part of the product, not an afterthought.

Omepikya Expense handles information that can be financially sensitive. The application therefore uses multiple layers of protection across account access, local app usage, and supported cloud features.

✓
Authenticated account access

Cloud-enabled functionality is built around authenticated users rather than treating financial information as openly accessible data.

✓
Protected sessions

Account-based features use protected application sessions so authenticated access can be maintained without exposing account credentials unnecessarily.

✓
Biometric protection

Where supported and enabled by the user, biometric authentication can provide an additional layer of protection when accessing the application.

✓
Secure network communication

Supported cloud communication is designed to use secure application network flows when exchanging information with backend services.

✓
Local application protection

Information stored or used locally is handled within the application's Android environment and its defined data flows.

✓
Security-conscious architecture

Authentication, synchronization, local data handling, and account access are treated as separate security concerns as the platform continues to evolve.

✓
Responsible disclosure

If you discover a security issue in Omepikya, please contact us privately before publicly disclosing technical details so the issue can be investigated.
